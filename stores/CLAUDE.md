# stores/ — آلية داخلية مجمّدة

مجلدات `stores/<slug>/` آلية داخلية قديمة لتخصيص متجر بعينه (أقسام ومكوّنات وصفحات خاصة بمتجر واحد). **لا يُبنى بها أي متجر جديد**:
المتاجر الجديدة يُنشئها وكيل الرسائل آلياً بتصميم Colapia Core الموحّد، ويكمل صاحبها الإعداد من لوحته (انظر `docs/V2-PLAN.md`).

- المجلدات القائمة تبقى تعمل كما هي (السجل المولَّد `src/stores/registry.generated.ts`، والحارس `npm run stores:check`).
- لا استمارة ولا لوحة إنتاج ولا مهارات بناء ولا تعليمات لـ Claude Code في هذا المسار بعد الآن.
- أي تغيير في المنصة نفسها يُكتب في `CLAUDE.md` الجذر، لا هنا.

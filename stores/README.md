# stores/ — تخصيصات متاجر العملاء

كل مجلد هنا متجر واحد باسم نطاقه الفرعي (`<slug>.colapia.com`). الدليل الكامل لبناء متجر: [`CLAUDE.md`](CLAUDE.md)، ومعيار الجودة: [`QUALITY.md`](QUALITY.md).

- متجر جديد: انسخ `_template/` إلى `stores/<slug>/` (أو يُنشأ آلياً من لوحة الإنتاج) ثم اتبع `CLAUDE.md`.
- المجلدات التي تبدأ بـ `_` لا تُسجَّل كمتاجر.
- `nova` و`atelier` متجرا معاينة محلية يوضحان كل نقاط التخصيص.

# QUALITY.md — معيار جودة متجر عميل (من 100)

> يقيّم به Claude Code والمراجع كل متجر قبل التسليم. **الحد الأدنى للتسليم: 91.** أي «مانع» = لا تسليم مهما كانت النتيجة.
> قيّم من لقطات حقيقية (`preview.sh shot ... --store=<slug>`) على 375px وسطح المكتب، لا من الكود وحده. اكتب النتيجة بنداً بنداً في `DELIVERY.md`.

## موانع (أي واحد منها = إيقاف التسليم)
- فشل `npm run stores:check` أو `npx tsc --noEmit`.
- تمرير أفقي على 375px في أي صفحة، أو خطأ في console المتصفح.
- ادعاء غير صحيح: تقييم أو رقم أو سياسة (شحن مجاني، استبدال، دفع عند الاستلام) غير موجودة في `BRIEF.md` أو `kit.facts`.
- سعر منتج لم يعطه التاجر، أو منتج ليس من منتجاته.
- صفحة أساسية مكسورة: الرئيسية، منتج، قسم، السلة، الدفع حتى صفحة تأكيد الطلب.
- نص إنجليزي أو نص تجريبي (lorem، «عنوان هنا») يظهر للزبون.

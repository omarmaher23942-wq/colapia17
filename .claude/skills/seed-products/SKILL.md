# تجهيز المنتجات

1. المصدر الوحيد: `BRIEF.md` و`brief/` (صور المنتجات وسطر لكل منتج، أو ملف جمعه الفريق من صفحة التاجر). لا منتج ولا سعر من خيالك.
2. الصيغة في `src/stores/seed.ts`:
   ```json
   { "categories": [{ "name": "فساتين" }],
     "products": [{ "name": "فستان كتان صيفي", "price": 450, "compareAt": 599, "stock": 14, "category": "فساتين",
                    "description": "…", "images": ["brief/assets/dress-1.jpg"], "featured": true,
                    "options": { "المقاس": ["S", "M", "L"] } }] }
   ```
   - السعر بالجنيه كما كتبه التاجر. `compareAt` فقط إن ذكر سعراً قبل الخصم.
   - `stock` فقط إن ذكر كمية؛ بدونها المنتج متاح دائماً.
   - اسم وصفي يبحث به الزبون («فستان كتان صيفي» لا «موديل 12»).
   - الوصف: ما يهم الزبون فعلاً (الخامة، المقاس، الاستخدام) من كلام التاجر وصوره، بلا مبالغة ولا ادعاء.
   - `featured` لـ 3–6 منتجات تمثل المتجر.
3. ما ينقص (سعر، مقاسات) يُكتب في `DELIVERY.md` تحت «أسئلة للعميل»، ولا يُخمَّن.
4. `npm run stores:registry` (يفحص الصيغة) ثم `bash scripts/dev/preview.sh store <slug>` وشاهد الكتالوج.

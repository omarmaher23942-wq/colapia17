# {{STORE_NAME}}: متجرك ولوحة تحكمه

هذا المشروع هو متجرك كاملاً (واجهة المتجر + لوحة التحكم)، مولّد من Colapia بتصميم متجرك نفسه: ألوانه وخطوطه وأقسامه.
يعمل على حساباتك المجانية وحدها، بلا أي اشتراك أو عمولة، ولا يعتمد على Colapia في تشغيله.

## التشغيل لأول مرة (من الموبايل)

1. **Vercel:** من vercel.com/new اختر هذا المستودع واضغط Deploy كما هو.
2. **قاعدة البيانات:** في مشروعك على Vercel افتح Storage، ثم Create Database، ثم Neon، واختر المنطقة Frankfurt، ثم Connect.
   بعدها افتح Deployments وأعد النشر (Redeploy).
3. **الاستلام:** افتح `https://موقعك/setup`. الصفحة تجهّز القاعدة وحدها، ثم تطلب:
   - كود الاستلام من لوحة Colapia (صفحة «امتلك متجرك»).
   - بريدك وكلمة مرور للوحة التحكم.
   - مفتاح UploadThing لصورك (مجاني من uploadthing.com، صفحة API Keys).
4. بعد الاستلام تصلك **كود استرجاع**: احفظه، فهو الطريقة الوحيدة لإعادة تعيين كلمة المرور إن نسيتها.

## الاستخدام اليومي

- **المتجر:** الصفحة الرئيسية لموقعك.
- **لوحة التحكم:** `/dashboard` على نفس الموقع.
- **المفاتيح:** من اللوحة افتح «الربط والمفاتيح»: مفتاح الصور (UploadThing)، ومفتاح الذكاء الاصطناعي (Groq، مجاني).
  المفاتيح تُحفظ في قاعدتك أنت، وتُختبر قبل الحفظ.

## نطاقك الخاص (اختياري)

في Vercel افتح Settings ثم Domains وأضف نطاقك (مثل `{{SUBDOMAIN}}.com`)، واتبع تعليمات DNS التي تظهر لك.
لا تحتاج تعديل أي شيء في الكود.

## على الكمبيوتر (للمطورين)

```bash
npm install
cp .env.example .env.local   # ثم ضع رابط قاعدة Neon في DATABASE_URL
npm run dev
```

- `src/store.config.ts`: هوية متجرك.
- `src/app/store-theme.css` و`src/lib/fonts.ts`: ألوان متجرك وخطوطه.
- `store/blueprint.json`: نسخة من تصميم متجرك وقت الاستلام (التصميم الحي في قاعدتك ويُعدّل من اللوحة).
- `drizzle/`: مخطط قاعدة بياناتك.

## الأمان والنسخ الاحتياطي

- لا تضع أي مفتاح داخل الكود أو في GitHub. المتغير الوحيد في Vercel هو رابط القاعدة، ويضيفه Neon وحده.
- Neon يحتفظ بنسخ احتياطية تلقائية، ويمكنك الاستعادة من لوحة Neon (Branches، ثم Restore).

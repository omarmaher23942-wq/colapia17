# نظام تصميم المتجر (V3)

> مرجع شريحة W-A. التنفيذ: `src/blueprint/themes.ts` (الهويات)، `src/blueprint/theme.ts` (الألوان والخطوط والخلفية)، `src/blueprint/design.ts` (الأشكال والبطاقات والحركة)، `src/components/storefront/CardFx.tsx` (حركة البطاقات بمستمع واحد).

## 1) المبادئ
- **تصميم واحد = هوية كاملة**: ألوان الوضعين، خطّان، زوايا، بطاقة، أزرار، هيدر، حركة، خلفية. التاجر يختار ثم يعدّل أي جزء.
- **كل لون توكن**: لا لون ثابت في مكوّنات المتجر. الخلفية والأسطح والنص تأتي من الـ Blueprint، ومع كل لوحة يُفرض تباين AA آلياً (النص 4.5:1 على الأقل على الخلفية والأسطح والأزرار).
- **بلا قفزة تخطيط**: كل الصور بنسب ثابتة (`aspect-ratio`)، وكل الحركة `transform`/`opacity`/متغيرات CSS فقط.
- **الحركة مهذبة**: تتوقف كلها مع «تقليل الحركة»، وحركة البطاقات تعمل فقط وهي ظاهرة في الشاشة.

## 2) التوكنات (على `.storefront`)
| التوكن | المعنى |
|---|---|
| `--bg` = `--background` | خلفية الصفحة (لون مصمت، والتدرج/النسيج طبقة فوقه من `theme.background`) |
| `--surface` = `--card` | سطح البطاقات والنوافذ |
| `--surface-2` = `--muted` | سطح ثانوي (خلفية الصور، الحقول، الأقسام البديلة) |
| `--text` = `--foreground` | النص الأساسي (≥ 7:1 حيث أمكن، و4.5:1 حداً أدنى) |
| `--text-muted` = `--muted-foreground` | النص الثانوي (≥ 4.5:1 على `--surface-2`) |
| `--primary` / `--primary-contrast` | لون العلامة ونص الأزرار فوقه |
| `--accent` / `--accent-foreground` | الإبراز (شارات، توهج، تفاصيل) |
| `--border` / `--ring` | الحدود وحلقة التركيز |

ملاحظة: `--muted` بقي اسماً لسطح ثانوي لأن عشرات المكوّنات تستخدمه، والنص الثانوي اسمه `--text-muted`.

## 3) الطباعة والمسافات
- مقياس العناوين: `s-display` ‏clamp(2.1rem→4.4rem)، `s-title` ‏clamp(1.5rem→2.4rem)، نص 16px بارتفاع سطر 1.75.
- الخطوط من `AVAILABLE_FONTS` فقط، وكل تصميم زوج (عنوان/نص).
- المسافة العمودية للأقسام: `--section-y` (هادئ/متوازن/مضغوط)، والحاوية 68/78/90rem، وهامش جانبي 16px على الجوال.
- الزوايا: الافتراضي «متوسط مستدير» 14px للبطاقة و12px للأزرار والحقول.

## 4) البطاقات (`bp.design.cardStyle`)
| الأسلوب | الشكل |
|---|---|
| `mercury` | زوايا 14px، إطار بدرجة عميقة من الهوية (لا يساوي الخلفية)، ولمعة زئبقية تسري حول الإطار (`conic-gradient` + `@property --s-angle`)، وتوهج داخلي خافت. على الكحلي تصير فضية زرقاء. |
| `cinematic` | ميل ثلاثي الأبعاد مع المؤشر، لمعة تتبعه، وعمق للصورة (parallax داخلي). |
| `glow` | توهج ناعم بلون الإبراز وارتفاع خفيف عند المرور. |
| `simple` | نظيف بحد رفيع بلا ظل. |

`CardFx` يضع `data-in` على البطاقات الظاهرة فقط (IntersectionObserver واحد)، والإطار المتحرك يعمل عليها وحدها، والميل مستمع واحد بمؤشر دقيق.

## 5) الأقسام والحركة
- كل قسم يظهر بدخول ناعم، وشبكات المنتجات بدخول متدرج مرتبط بالتمرير (`animation-timeline: view()`) بلا جافاسكربت، والمتصفحات غير الداعمة ترى المحتوى ثابتاً.
- الهيدر زجاجي (`backdrop-filter`) بلون الخلفية، والشعار بارتفاع محجوز (لا قفزة).
- الواجهة ثلاثة أوضاع: فيديو كامل بغلاف، صورة جانبية متوسطة، منتج بطل.
- فاصل الأقسام حسب التصميم (خط، منحنى، بلا).

## 7) الخلفية (`bp.theme.background`)
`{kind: solid|gradient|texture, color, color2?}`. اللون الأساسي يكتب `--background` نفسه (فتتغير الخلفية فعلاً مع أي تعديل)، والتدرج أو النسيج طبقة فوقه. كانت الخلفية سابقاً تُشتق في الوضع الداكن من لون العلامة وحده وتتجاهل اختيار التاجر؛ صار الوضع المقابل يُشتق من خلفية التاجر نفسها.

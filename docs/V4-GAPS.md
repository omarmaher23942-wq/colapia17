## 6) ما لن يُنفَّذ الآن (وسبب صادق)
- **شات Claude داخل لوحة المالك:** ألغاه المالك؛ التعديل بـ Claude Code مباشرة على مستودع العميل.
- **ميزات تعتمد على اشتراكات/ملكية متعددة المستأجرين:** محذوفة.
- **ذكر الخطط المستقبلية في أي واجهة:** ممنوع.
- **100–200 ميزة:** تنفذها شرائح F1–F4 (40–50 لكل منها)؛ العدد الفعلي يُسجَّل في `docs/V4-FEATURES.md` بحالة كل ميزة.

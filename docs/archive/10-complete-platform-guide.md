# Colapia | الدليل التشغيلي والمعماري الشامل (Production Master Guide)

تم تحديث المنصة لتصبح نظاماً متكاملاً للإنتاج بنسبة 1000% جاهزاً لاستقبال آلاف المتاجر والطلبات في السوق المصري.

---

## 1. فلسفة العرض والتسعير (Pricing Strategy)
- **السعر الأساسي المرجعي (Anchor Price):** **8,999 جنيه مصري**.
- **عرض الإطلاق الاستثنائي:** لأول 30 متجراً فقط، خصم 90% لامتلاك المتجر للأبد بـ **899 جنيه مصري فقط** دفعة واحدة مدى الحياة (بدون أي اشتراك شهري وبدون أي عمولة على المبيعات نهائياً).
- **قفل الخصم بالمراجعة الصوتية (Review Gated):** يتاح للتاجر تجربة المتجر مجاناً لمدة **180 دقيقة نشطة**. للحصول على كود خصم الـ 899 ج، يشارك تقييماً وفويس نوت بصوته، ويظهر التقييم في اللاندينج بعد اعتماد الأونر مع إمكانية تصديره كصورة إعلانية للفيسبوك والإنستاجرام.

---

## 2. المعمارية الفنية (Technical Architecture)
1. **Next.js 15 (App Router) + Serverless Edge Multi-tenancy:**
   - الدومين الرئيسي `colapia.com`: لصفحة الهبوط واستمارة البناء ولوحة تحكم المنصة (`/admin`).
   - الدومينات الفرعية `*.colapia.com`: يُعاد توجيهها داخلياً عبر `middleware.ts` إلى `/s/[store]`.
2. **قاعدة البيانات (Neon Serverless Postgres + Drizzle ORM):**
   - حماية المخزون من البيع بالسالب ذرياً (`CHECK stock >= 0`).
   - دمج إيصالات فودافون كاش وإنستاباي مع الطلبات في عملية ذرية واحدة لمنع ضياع الإيصالات.
3. **محرك الإيميلات والمعاملات (Resend):**
   - إرسال إشعارات فورية للتاجر عند ملء الاستمارة وعند جاهزية المتجر وعند وصول أي أوردر جديد.
   - إرسال فواتير تأكيد الشحن للمشتري النهائي.
   - أداة البرودكاست الجماعي من لوحة الأونر.
4. **الذكاء الاصطناعي (AI Pipeline):**
   - Closer Agent يبيع عرض الـ 899 ج ويرسل الرابط فوراً.
   - Architect و Composer يولدون خطة بناء المتجر والـ SEO الديناميكي وجداول المواصفات الفنية ومنع الفيديوهات المباشرة واقتصارها على Vimeo و YouTube.

## 3. أوامر التشغيل الأساسية (Commands)
```bash
# تثبيت الحزم
npm install

# توليد وترقية قاعدة البيانات
npm run db:generate
npm run db:push

# تصفير وتنظيف قاعدة البيانات استعداداً للإطلاق (مسح البيانات الوهمية)
npx tsx scripts/clean-db.ts

# تشغيل السيرفر محلياً
npm run dev

# فحص الـ Types قبل النشر
npm run typecheck
npm run build
```

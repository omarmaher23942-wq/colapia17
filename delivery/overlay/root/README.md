# {{STORE_NAME}}

هذا مشروع متجركم الإلكتروني ولوحة التحكم، وهو ملك لكم بالكامل. يعمل على حساباتكم أنتم: Cloudflare للنشر، وNeon للبيانات، وImageKit للصور.

## كيف يعمل (للمالك)
1. **الموقع** هو متجركم للزوار، و**لوحة التحكم** على الرابط `/dashboard` تديرون منها الطلبات والمنتجات والعملاء والشحن والشكل.
2. **الدخول:** بالبريد `{{OWNER_EMAIL}}` وكلمة المرور التي اخترتموها عند الإعداد الأول. إن نُسيت كلمة المرور فصفحة «نسيتم كلمة المرور؟» ورمز الاسترجاع الذي حفظتموه يعيدان الدخول.
3. **الصور:** تُرفع من اللوحة مباشرة. **الفيديو:** ملف MP4 واحد للواجهة يُضغط تلقائياً قبل الرفع.
4. **الميزات الذكية** (قراءة صور المنتجات وكتابة الأوصاف) تعمل بمفتاح Groq الخاص بكم من «الربط والمفاتيح» في اللوحة، وهي اختيارية.

## ماذا أفعل إن احتجت تعديلاً؟
من أسفل لوحة التحكم اضغطوا «طلب تعديل». وتجدون الخطوات التقنية في `docs/SETUP.md`، وللتعديل بأداة Claude Code الملف `CLAUDE.md`.

## الأوامر
```
npm install
npm run dev          # تشغيل محلي
npm run typecheck    # فحص الأنواع
npm run cf:deploy    # بناء ونشر على Cloudflare
```
